# 🎬 Netflix Movies Analysis (1990s)

![Banner](images/redpopcorn.jpg)

Análisis exploratorio de datos (EDA) centrado en las películas estrenadas durante la década de 1990 en la plataforma Netflix.

## 📌 Objetivos
- Determinar la duración más frecuente (moda) de las películas de los años 90.
- Contabilizar cuántas películas de acción de los 90s duran menos de 90 minutos (películas cortas).

## 📊 Principales Hallazgos
- **Duración más frecuente:** 94 minutos.
- **Películas de acción cortas (<90 min):** 7 títulos.

## 🛠️ Tecnologías Utilizadas
- **Lenguaje:** Python
- **Librerías:** Pandas, Matplotlib
- **Entorno:** Jupyter Notebook
